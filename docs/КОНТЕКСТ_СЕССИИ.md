## 9. Открытый вопрос (нужно решение)

В конфигурации нет операции «привязка без изменения»: физическое подключение базы
к существующему хранилищу возможно только через `/ConfigurationRepositoryUpdateCfg`
(привязка + обновление конфигурации до версии) и выполняется при конвертации. Варианты:

1. **Оставить только логическую привязку** (рекомендую) — физическое подключение произойдёт
   при первой конвертации (каждая база под своим пользователем).
2. Выполнить `ConfigurationRepositoryUpdateCfg -force -v 251 -UpdateDBCfg` каждой базой
   под её пользователем (загрузит текущую конфигурацию хранилища).
3. Вручную указать целевую версию.

## 1. Что сделано

### 1.1 Блок A — формулировки об ibcmd приведены в правду

| Что | Объём |
|---|---|
| Сообщения об отказе «ibcmd supports file infobases only» переписаны: запрет подан как **ограничение навыка**, а не возможностей утилиты (11 скиллов × `.ps1` + `.py`) | 22 сообщения |
| Комментарии `# --- ibcmd branch (file infobase only …) ---` снабжены ссылкой на `docs/ibcmd/` | 16 комментариев |
| `db-cfe-admin/SKILL.md`: уточнено, что свойства читает `ibcmd` и навык отдаёт ему только файловую базу | 2 места |

Смысл новой формулировки: сама утилита работает и с СУБД (`--dbms`, `--db-name`, `--db-server`,
`--db-user`, `--db-pwd`), и с работающим автономным сервером (`--pid`, `--remote`); навыки ограничены
намеренно, потому что в offline-режиме `ibcmd` поднимает собственный автономный сервер против СУБД,
и базу, которую держит живой кластер, отдавать под второй движок нельзя.

### 1.3 Новые навыки

#### `db-eventlog` — выгрузка журнала регистрации

| | |
|---|---|
| Файлы | `SKILL.md`, `scripts/db-eventlog.ps1`, `scripts/db-eventlog.py` |
| Команды | `export` (по умолчанию), `model` (XSD-схема модели событий) |
| Параметры | `-LogPath`, `-DataDir` (берёт `<DataDir>\log-data`), `-Format xml\|json`, `-From`, `-To`, `-Out`, `-SkipRoot`, `-Follow`, `-V8Path`, `-AdditionalIbcmdArguments` |
| Коды возврата | `0` — выгружено; `1` — ошибка запуска/разбора либо файл не создан при коде 0 платформы; `2` — событий не было; прочие — код платформы с пояснением аварийного завершения |
| Особенность | `eventlog` не принимает `--data`/`--db-path`: читает **каталог журнала**, а не базу, поэтому реквизиты базы навыку не нужны |
| Ограничение | журнал кластерных баз проекта лежит в СУБД — там работает MCP-1С `get_event_log` |
| Проверено | выгрузка xml/json/XSD на реальном `log-data`, автопоиск `ibcmd` без `-V8Path`, относительный путь запуска, все guards |

#### `db-session` — сеансы и блокировки автономного сервера

| | |
|---|---|
| Файлы | `SKILL.md`, `scripts/db-session.ps1`, `scripts/db-session.py` |
| Команды | `list`, `info`, `terminate`, `interrupt`, `locks` |
| Параметры | `-ProcessId` (процесс `ibsrv.exe` на этой машине), `-Remote` (шлюз на другой машине), `-Session`, `-ErrorMessage`, `-Licenses`, `-V8Path`, `-AdditionalIbcmdArguments` |
| Особенность | `session`/`lock` принимают **только** `--pid`/`--remote`; навык проверяет, что процесс существует и это именно `ibsrv` |
| Пустой вывод | `session list` без сеансов и `session info` несуществующего сеанса дают код `0` с пустым выводом — навык отличает это от успеха |
| Проверено | поднят настоящий `ibsrv.exe` на временной базе: `session list`, `lock list`, все guards; сервер после проверки остановлен |

## 4. Грабли, на которые стоит обратить внимание при правке скиллов

| Грабля | Следствие |
|---|---|
| **`.ps1` обязан быть с BOM.** Без BOM Windows PowerShell 5.1 читает файл как ANSI и ломает кириллицу в строках — скрипт не запускается вообще | при записи файла из PowerShell использовать `[System.Text.UTF8Encoding]::true`; `.py` — наоборот, без BOM |
| `Set-Content -Encoding UTF8` в PS 5.1 **добавляет BOM** | не использовать для `.py` |
| `$Pid` — встроенная read-only переменная PowerShell | навык называет параметр `-ProcessId` (в `db-session` это выяснилось сразу при прогоне) |
| `ProcessStartInfo.ArgumentList` есть только в .NET Core | на Windows PowerShell 5.1 строку команды собирать вручную (взят подход из `db-cfe-admin`) |
| Регулярка с `$` в многострочном режиме .NET не съедает `\r` | для CRLF-файлов нужен `[ \t]*\r?$`, иначе замена молча не срабатывает |
| Массив из одного элемента в PowerShell разворачивается | `ConvertFrom-IbcmdRecords` обёрнут в `@(...)`, иначе `.Count` у словаря считает **ключи** записи, а не записи |
| Вендорский справочник по `ibcmd` местами неверен | при сомнении — `ibcmd help <режим>`: он печатает контракт установленной платформы |
| Общий блок helper-функций в `.py` должен совпадать дословно | в группе `db-*` его держит одинаковым внешний `tests/skills/check-inline-drift.mjs` (в этом репозитории теста нет, но требование зафиксировано в коде) |

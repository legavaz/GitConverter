# Матрица расхождений: ibcmd по документации ↔ ibcmd в скиллах

Дата сверки: 02.10.2026. Источник возможностей — [ВЕНДОР-IBCMD-4.10.md](ВЕНДОР-IBCMD-4.10.md).
Сторона «скиллы» проверена по исходникам `.opencode/skills/*/scripts/*.{ps1,py}`.

## 0. Как скиллы выбирают движок

Общее для всех: движок определяется **именем файла** в `-V8Path`
(`Split-Path $V8Path -Leaf -match '^ibcmd'` / `os.path.basename(v8path).lower().startswith("ibcmd")`).
Дополнительные аргументы разводятся по параметрам `-AdditionalV8Arguments` (1cv8) и
`-AdditionalIbcmdArguments` (`--ключ=значение` через запятую); параметры другого движка — ошибка.
Значения по умолчанию для ibcmd можно задать в `.v8-project.json` (ключ `ibcmdargs`).

## 1. Главное расхождение: файловая база vs СУБД

Вендор: `--dbms=<MSSQLServer|PostgreSQL|IBMDB2|OracleDatabase>`, `--db-name/--db-server/--db-user/--db-pwd/-W`,
плюс подключение к работающему автономному серверу `--pid` / `--remote`.

## 2. Что скиллы уже используют корректно

| Скилл | Команда ibcmd | Позиция |
|---|---|---|
| db-create | `infobase create --db-path=… --create-database` | `db-create.ps1:442` |

| db-load-cf | `infobase config load <cf> --db-path=` | `db-load-cf.ps1:561` |
| db-dump-xml | `config export` / `export objects` / `export all-extensions` | `db-dump-xml.ps1:587-601` |

| db-dump-dt | `infobase dump <dt> --db-path=` | `db-dump-dt.ps1:454` |
| db-load-dt | `infobase restore <dt> --db-path=` | `db-load-dt.ps1:477` |

`--extension`, а также проверка постфактум — «код 0, но файл пуст» трактуется как ошибка.

## 4. Ошибки, не связанные с ibcmd, всплывшие при сверке

`--force` у ibcmd — это **«автоматически подтверждать выполнение операции при наличии предупреждений»**, а не
«завершить сеансы». Завершение сеансов у ibcmd — отдельный параметр (`restore --force` +
`--session-terminate-message`, `apply --session-terminate=force`). В `db-update`/`db-load-xml` параметр
`--force` выставляется всегда и несёт именно смысл «подтверждать предупреждения» — совпадение корректное,
но при документировании параметров это легко перепутать.

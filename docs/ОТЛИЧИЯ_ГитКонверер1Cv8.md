### 2.8 Общий модуль `КонвертацияХранилища` (`Module.bsl`, +696/−38) — основная доработка
**Суть: переход временных баз конвертации с файлового режима на серверные (пул из `ноВременныеБазы`/`ноКластеры`).**

Новые процедуры/функции:
| Имя | Назначение |
|---|---|
| `УстановитьПользователяХранилищаВременнойБазы(РеквизитыБазы, Параметры)` | Заполняет пару «пользователь/пароль хранилища» для временной базы (через `ноПользователиХранилища` или старые поля) |
| `ДобавитьПользователяХранилища(ВременнаяБаза, Администратор)` (Экспорт) | Создание пользователя хранилища для временной базы |
| `КонвертацияВыполняется(Знач Хранилище)` | Признак идущей конвертации хранилища |
| `СсылкаВерсииПоУИД(Знач Ключ)` / `СсылкаОчередиПоУИД(Знач Ключ)` | Восстановление ссылки по GUID из параметров фонового задания |
| `ОсвободитьВременныеБазыХранилища(Знач Хранилище)` (Экспорт) | Очистка «зависших» занятых баз пула после прерванных запусков |
| `ОчиститьСсылкиВерсийНаВременнуюБазу(Знач ВременнаяБаза)` | Сброс реквизита `ВременнаяБаза` у версий |
| `СтрокаСозданияСервернойБазы(Параметры)` | Строка `CREATEINFOBASE Srvr=…;Ref=…;DBMS=…;DBSrvr=…;DBUID=…;DBPwd=…;DB=…;Locale=ru_RU` (в т.ч. выбор `PostgreSQL`/`MSSQL` из `ноТипыСУБД`) |
| `ПолучитьКластерВременныхБаз(Хранилище)` (Экспорт) | Кластер из реквизита хранилища (учитывая `ИспользоватьСерверныеВременныеБазы`) |
| `ПараметрыПодключенияККластеру(Кластер, Параметры)` | Параметры соединения с кластером (адрес сервера, пользователи СУБД/кластера) |
| `ПолучитьИмяПользователяИБ(Кластер)` | Имя OS-пользователя для подключения к серверной ИБ |

Изменения существующей логики:
- **`ноВыполнитьКонвертацию`**: проверка флага `ОстановитьКонвертацию` (журнал `КХ.ноВыполнитьКонвертацию.Остановлена` + выход); если конвертация не идёт — автоосвобождение занятых временных баз (`ОсвободитьВременныеБазыХранилища`); для формирования отчёта тоже берётся свободная база пула (`КХ.ноВыполнитьКонвертацию.НетСвободныхБаз`).
- **`ноПолучитьВерсиюВБазу`**: вместо создания файловой ИБ — поиск свободной базы пула (`ноВременныеБазы.НайтиСвободную`), при отсутствии — предупреждение `КХ.ноПолучитьВерсиюВБазу.НетСвободныхБаз` и возврат версии в очередь; база помечается занятой (`Занять`); добавочно создаётся каталог временных файлов.
- **`ПолучитьПараметрыОбработкиВерсии`**: реквизиты + `ВременнаяБаза`; если задана — восстановление подключения к серверной базе (адрес кластера, `СтрокаСоединенияИБ = " /S сервер\база"`, OS-пользователь через `ПолучитьИмяПользователяИБ`).
- **`ВыгрузитьКонфигурациюВФайлы` (дамп)**: в конце — контроль, что каталог выгрузки не пуст, иначе исключение.
- **`CREATEINFOBASE`**: параметризирована (`%СтрокаСозданияБазы%`) — серверная (`СтрокаСозданияСервернойБазы`) или файловая, в зависимости от наличия пула.
- **`УдалитьФайлыВерсии` / `УдалитьФайлыВерсииВФоне` / проверка при записи**: дополнительно освобождается серверная база (`ноВременныеБазы.Освободить`, обнуление `Объект.ВременнаяБаза`).
- **Запись метаданных/индексов**: `КоличествоМетаданных` теперь = `Объект.Состав.Количество()` (было `ТаблицаИндексовПредыдущейВерсии.Количество()`).

### 2.9 Общий модуль `СтроковыеФункцииКлиентСервер` (`Module.bsl`, +79)
- Новая функция **`ТранслитерироватьСтроку(Знач Строка)`** (Экспорт): кириллица → латиница, недопустимые символы/пробелы → `_`, нижний регистр, схлопывание/обрезка `_`. Пример: `"Тестовая база №1"` → `testovaya_baza_1`. Используется для формирования имени серверной временной базы из наименования.

### 2.10 Служебные файлы
- `ConfigDumpInfo.xml` — служебный (версии/hash метаданных), расхождение ожидаемо.
- `Ext\ParentConfigurations.bin` — бинарный служебный, расхождение генерируемое.
- `Configuration.xml / InternalInfo ObjectId` — генерируемый UUID, не смысловое отличие.

## 3. Резюме

**Одно общее направление доработок:** перевод конвертации с файловых временных баз на **серверные временные базы** через пул:
- справочники `ноКластеры` → `ноВременныеБазы` → `ноПользователиХранилища`;
- включение режима на хранилище (`ИспользоватьСерверныеВременныеБазы` + `КластерВременныхБаз`);
- «красная кнопка» останова `ОстановитьКонвертацию`;
- автоосвобождение зависших баз и параллельность через «один пользователь хранилища = одна временная база».

Побочные мелочи, найденные при сравнении (не связаны с серверным пулом): отладочная строка `//dvi` `КоличествоМетаданданных = Состав.Количество()` в `ВерсииХранилища.ObjectModule`, снятие проверки версии платформы 8.3.10, `FillChecking` → `DontCheck`, функция транслитерации.

## Порядок выполнения (когда решите чистить)

1. **Свериться с реестром** `docs/ЗАЩИЩЁННЫЕ_АРТЕФАКТЫ.md` (Правило 6) — ни один объект из разделов A/B/C
   в реестр не входит, кроме явно отмеченных (`tools1C\ГитКонверер1Cv8_0809.cf`, `tools1C\opencode-export`).
2. **Зафиксировать состояние до:** `git status --short` (документы) и `Get-ChildItem <путь> -Recurse | Measure-Object`.
3. **Удалять по одному объекту**, начиная с мелких (TEMP → `qwery` → `_probe_ext` → архивы `.7z` → `_ext_probe`),
   чтобы в любой момент можно было остановиться.
4. **Проверить после:** `git status --short` (должны появиться только `D docs/…`, если удаляли документы),
   свободное место на `E:`, работоспособность конвейера (файлы `log.txt`/`result.txt` в `E:\rep\erp25_temp`
   обновляются каждые ~5 минут) — Правило 2 (Журнал регистрации) при этом не затрагивается, операции в 1С не выполняются.
5. **Обновить ссылки в документах** (перечень правок приведён в разделах A и B построчно).
6. При удалении `_ext_probe`: проверить в базе, что **тестовый** элемент хранилища с адресом
   `E:\rep\_ext_probe\repo` больше не нужен (в конвейере он не участвует), и при необходимости удалить сам элемент.

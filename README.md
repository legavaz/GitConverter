# GitConverter — конвертация хранилища 1С в Git

> Проект: `E:\project\0509 git converter` · ветка `lega-master` · репозиторий https://github.com/legavaz/GitConverter.git
> Обновлено: 27.09.2026

## Что это

Конфигурация 1С **«1С:ГитКонвертер, ред. 1.0»** (версия 1.0.5.8) + внешний движок **gitsync**:
перенос истории хранилища разработки 1С в Git-репозиторий (гибрид: пул временных баз ГитКонвертера
+ движок gitsync). Ядро — общий модуль `cfg_src/gitConverter/CommonModules/КонвертацияХранилища`.
